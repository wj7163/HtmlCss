# ☕ 바이브 카페 (Vibe Cafe)

> "당신의 하루에 바이브를 더하다"  
> HTML, CSS, JavaScript로 구현한 반응형 카페 주문서 및 주문 내역 관리 웹 애플리케이션입니다.

---

## 📌 주요 기능

### 1. 실시간 주문서 (주문하기 탭)
- **실시간 금액 계산**: 음료, 사이즈, 추가 옵션, 수량 선택에 따라 예상 금액을 실시간으로 계산하여 표시합니다 (`toLocaleString` 천 단위 콤마 적용).
- **입력 유효성 검사**: 주문 전 이름 및 음료 선택 필수 여부를 검사합니다.
- **주문 접수 확인**: 주문 완료 시 선택한 상세 내역(옵션, 수량, 총 금액)이 담긴 안내 메시지를 화면에 출력합니다.
- **다시 작성**: 주문서의 입력값 및 예상 금액을 기본값(M 사이즈, 수량 1개, 0원)으로 초기화합니다.

### 2. 주문 내역 관리 (주문 내역 탭)
- **탭 네비게이션**: 상단 탭을 통해 '주문하기'와 '주문 내역' 화면을 자유롭게 전환할 수 있습니다.
- **주문 건수 배지**: 현재 접수된 총 주문 건수가 탭 옆 배지에 실시간 반영됩니다.
- **최신순 정렬**: 접수된 주문이 최신순으로 상단에 추가됩니다.
- **개별 주문 취소**: 확인 창(`confirm`)을 거쳐 특정 주문을 안전하게 취소할 수 있습니다.
- **총 금액 요약 및 전체 삭제**: 전체 주문 건수와 누적 금액을 요약 표시하며, 한 번에 내역을 초기화할 수 있습니다.

### 3. 디자인 & 반응형 UI
- 따뜻한 카페 무드의 베이지 & 브라운 톤앤매너
- 부드러운 그림자와 둥근 모서리 디자인
- 모바일 환경에서도 최적화된 반응형 레이아웃

---

## 🛠 기술 스택
- **HTML5**: 시맨틱 태그 및 폼 접근성(label for/id, data-price 속성 활용)
- **CSS3**: Flexbox, 미디어 쿼리 기반 반응형 디자인
- **Vanilla JavaScript**: DOM 조작, 이벤트 핸들링, XSS 방지(`textContent` 활용)
